# 项目展示包使用说明

此文件夹可以单独复制或打包分享。它只包含静态页面、真实截图、演示视频和项目简介，不需要运行客服后端，不会请求模型接口。

## 查看

- 双击 `index.html`，查看完整展示页。页面无外部字体、脚本或统计服务，离线可用。
- 直接打开 `assets/video/agent-demo.mp4`，播放带中文字幕和合成旁白的演示视频。
- `assets/screenshots/` 保存真实运行截图，点击页面中的截图可以放大。
- `project-brief.md` 可作为作品集或面试附件。

若浏览器限制本地媒体或字幕，可在本目录运行：

```bash
python3 -m http.server 8010 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8010/ 。字幕已经烧录进视频，外置 `.vtt` 仅作为附加字幕轨道；无需同时开启两层字幕。

## 分享范围

只分享本目录或专门生成的展示包压缩文件。不要压缩整个开发仓库，也不要把仓库可见性改成公开。本目录的静态 HTML/CSS/JavaScript 属于展示页面，不包含 Agent 后端实现。

本地访问地址不能供其他人的电脑访问。对外在线展示需要另行部署这个静态目录；本次没有发布网站、创建远程仓库或开放客服 API。
