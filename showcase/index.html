A

混合检索覆盖不同问法

Dense 与 BM25 各召回 Top-50，RRF 融合，bge-reranker-v2-m3 精排 Top-10。品类先过滤，同义词只在检索侧扩展。

B

在生成之前决定是否能答

知识问题按 0.7 / 0.8 分档，并独立检查证据是否充分。高分不自动代表正确，退款问题通过政策检查后仍可查询订单。

C

副作用不交给模型自动执行

主力 Agent 使用只读业务工具。建工单经过单独确认入口并做幂等处理，转人工与建单互不绑定。

04 / ENGINEERING PRACTICE

把“能跑”推进到“可检查”。

2026-09-22 合并后验证，覆盖隔离数据库、检索与工作流。该数字是代码测试结果，不是模型回答准确率。

01

持久化与失败恢复

业务审计与图检查点分开保存；只有完整完成的历史轮次进入后续上下文。

02

预算、超时与停止条件

限制 Agent 决策次数、工具次数和整轮 token 预算；工具提供参数校验、超时与重试。

03

检索与生成分开评估

比较向量、BM25、混合、混合加重排；使用 Recall@K、MRR 与 Faithfulness 检查表现，保留失败样例。

当前边界

本项目为本地功能演示。业务工具返回模拟数据，转人工为前端模拟；未接真实电商、真人客服或生产鉴权。指代消解暂为透传，反馈仅保存在浏览器。正式模型评估仍存在失败与误判，不将选定演示样例外推为全量质量结论。
