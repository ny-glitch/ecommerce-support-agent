# 第 02 章客服工具调用 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有客服聊天页接通一次 Function Calling、五个业务工具、MySQL 持久化和流式回答，完成三条真实浏览器验收。

**Architecture:** FastAPI 路由适配聊天服务，聊天服务协调模型网关、工具执行器与 SQLAlchemy 仓储。一次选择、最多一个逻辑工具执行、一次不绑定工具的最终文本流；MySQL 保存完整审计，模型仅加载已完成轮次。

**Tech Stack:** Python >=3.11（本机3.13.2）、现有 FastAPI 0.141.1、langchain-core 1.6.3、langchain-openai 1.6.2；新增 SQLAlchemy[asyncio] 2.0.54、asyncmy 0.2.14、cryptography 46.0.3（MySQL默认认证必需；运行验证补齐）；Docker 官方 mysql:8.4.11。

**Spec:** `docs/superpowers/specs/2026-09-17-ch02-tools-design.md`，用户“规格通过”。

## Global Constraints

- 固定技术：Python、FastAPI、SQLAlchemy、Docker MySQL、LangChain `@tool`、OpenAI 兼容 Chat Completions 协议。
- 本章只允许一次模型工具选择、最多执行一个业务工具，然后收敛为最终回答。
- 一次逻辑工具执行允许有限的暂时性错误重试。
- 每次工具尝试默认5秒，最多尝试2次；整个请求受 `REQUEST_TIMEOUT_SECONDS` 限制。
- 不实现 Agent Loop、LangGraph、向量检索、RAG、真实订单/商品/物流接口或对应数据库表，不新增账号体系。
- DeepSeek 工具聊天的两个阶段均关闭思考模式；`LLM_CHAT_EXTRA_BODY={"thinking":{"type":"disabled"}}`，不改变售后提取。
- 四张业务表：`faq`、`conversations`、`messages`、`tickets`；创建时间UTC，内容utf8mb4。
- 工具结果最大4096个UTF-8字节；保留标识/状态/错误码及合法JSON。
- FAQ关键词取自本轮原文，字面LIKE，实际保留“邮费”漏召回。
- 后端实现走 Superpowers 和 TDD；Prompt、FAQ 数据质量以标注样例评估；聊天页面按用户指定的 Vibe Coding 例外直接修改和浏览器验证，不套页面 brainstorm、TDD 或 code review。
- 每完成一个任务或评审立即追记 `dev-notes/ch02.md` 的四项记录；不要在最后集中补记。
- 具体库API先查Context7；版本或固定技术发生不可解冲突时询问用户，不擅自换方案。
- `.env`、数据库密码、模型密钥不进入提交、命令输出或评估报告。保留用户已有密钥及上游模型设置。

async def test_seed_is_idempotent_in_real_mysql(mysql_db):
    await seed_database(mysql_db)
    async with mysql_db.engine.connect() as conn:
        before = tuple([(await conn.execute(text(f"SELECT COUNT(*) FROM {name}"))).scalar_one()
                        for name in ("faq", "conversations", "messages", "tickets")])
    await seed_database(mysql_db)
    async with mysql_db.engine.connect() as conn:
        tables = await conn.run_sync(lambda sync: inspect(sync).get_table_names())
        after = tuple([(await conn.execute(text(f"SELECT COUNT(*) FROM {name}"))).scalar_one()
                       for name in ("faq", "conversations", "messages", "tickets")])
    assert set(tables) == {"faq", "conversations", "messages", "tickets"}
    assert all(count > 0 for count in before)
    assert after == before
