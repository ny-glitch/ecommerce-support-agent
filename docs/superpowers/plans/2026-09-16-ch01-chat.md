# 电商客服纯对话 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可用 curl 验收的流式多轮客服和售后结构化提取 API。

**Architecture:** FastAPI 路由调用独立的模型适配器；模型适配器只使用 LangChain ChatOpenAI 的 OpenAI Chat Completions 协议。进程内会话按完整轮次保存，发送前裁剪并核算估算预算；售后提取使用 json_mode 与 schema 校验。

**Tech Stack:** Python 3.13（支持 >=3.11）、FastAPI 0.141.1、langchain-core 1.6.3、langchain-openai 1.6.2、Pydantic 2、pydantic-settings 2.15.0、Uvicorn 0.53.0、pytest 9.1.1、pytest-asyncio 1.4.0、HTTPX 0.28.1。以上直接依赖版本已从 PyPI 查询；安装后核对签名并冻结实际依赖。

**Spec:** `docs/superpowers/specs/2026-09-16-ch01-chat-design.md`

## Global Constraints

- 使用 Python、FastAPI、LangChain；地址、模型名、密钥从 `.env` 加载。
- 应用通过 ChatOpenAI 调用上游 OpenAI 兼容的 Chat Completions 接口。
- 本章不实现业务工具调用、Agent、数据库、RAG、订单查询或真实退款操作。
- 统一使用 `with_structured_output(..., method="json_mode")`，由 Pydantic 校验；不自动改用 function_calling。
- 单 worker、进程内会话、重启清空；不是生产鉴权服务，默认仅监听本机。
- SSE 事件 `meta`、`token`、`done`、`error`；按真实上游增量立即推送。
- 系统消息与当前输入不得被裁掉；历史仅裁完整轮次；失败与取消不能写入残缺轮次。
- `request_type` 枚举为 `refund`、`return_refund`、`exchange`、`repair`、`other`、`unknown`；其他两字段缺失为 `null`。
- 具体第三方库/API 先查 Context7；以已安装包签名核对版本。不得按相似类或其他语言的文档编写。
- 每任务 RED → GREEN → review；Prompt / 数据使用标注评估集；模型真实验收与离线测试分开报告。
- 主控在 brainstorm 定稿、计划评审、每任务完成、代码评审及 finish 后即时追记 `dev-notes/ch01.md` 四项记录。
- `.env`、虚拟环境、缓存、SDD 临时目录不提交；不得在输出中打印密钥。

- [ ] **Step 2: GREEN。** 路由在返回流前 acquire 会话并构建上下文；捕获输入超限释放占用。`meta` 包含会话 ID、`estimated_input_tokens`、`dropped_turns` 及计数为估算的标识。每个非空片段发送 `token: {"content": ...}`。正常结束且客户端未断开才 commit 完整轮次并发 `done`。

```python
# 生命周期必须包住整个事件流：
try:
    yield ServerSentEvent(event="meta", data=metadata)
    async for text in gateway.stream(window.messages):
        parts.append(text)
        yield ServerSentEvent(event="token", data={"content": text})
    store.commit(session, window.retained_turns + [Turn(message, "".join(parts))])
    yield ServerSentEvent(event="done", data={"session_id": session.id})
finally:
    store.release(session)
```

上述核心须补齐错误/断连/超时保护：取消不得被转成 done；流内异常发送安全 error 且结束；HTTP 开始前的领域异常按 `status_code` 返回。核对 FastAPI 实际 SSE API 后实现 generator 包装；确保客户端在等待上游期间断开也能取消任务，不能只在有 token 时检查连接。存储仅保留 `max_history_turns`，读上下文时还受预算限制；闲置会话按 TTL 清理，满额返回 503，禁止静默淘汰忙碌会话。
